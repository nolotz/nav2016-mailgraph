# Patch: Table 409 "SMTP Mail Setup" (NAV 2016)

Adds the Microsoft Graph fields 50100..50112 to Table 409. **Fields only** – no code, no triggers, no
functions. All logic (including the client secret helpers) lives in Codeunit 50400 "Graph Mail".

> This file does not contain the Microsoft object. Apply the change to the Table 409 in your own database.
> Field numbers 50100+ are in the customer range; change them if they collide with existing customizations
> (then also adapt Codeunit 50400 and the Page 409 patch – they reference the fields **by name**, so only the
> numbers in this table change).

Baseline: NAV 2016 Table 409 has fields 1–7 only (Primary Key, SMTP Server, Authentication, User ID,
Password, SMTP Server Port, Secure Connection), Version List `NAVW17.00`
([research-notes](../../docs/research-notes.md), "Dynamics NAV 2016 internals").

## Option A – C/SIDE Table Designer (recommended)

1. Object Designer → Table 409 → **Design**.
2. Go to the first empty line after field 7 and enter the 13 fields from the table above
   (Field No., Field Name, Data Type, Length).
3. For each field open **Properties** (Shift+F4) and set CaptionML, OptionString/OptionCaptionML,
   InitValue and TableRelation exactly as in the TXT snippet below. In the CaptionML/OptionCaptionML
   editor (AssistEdit) add one line for `ENU` and one for `DEU`.
4. Update the object's **Version List**, e.g. append `,NMG1.00`.
5. Save and compile (F11). Existing data is kept; new Boolean fields get their InitValue only for new
   records, so open Page 409 afterwards and check the Graph switches (see "Existing record" below).

## Existing record

Table 409 has a single record (Primary Key blank). Boolean `InitValue=Yes` only applies to records
inserted after the change. For the existing record the three Booleans are **No** after compiling.
Open Page 409 and set *Graph Save to Sent Items*, *Graph Reply-To Caller* and *Graph Large Messages* as
required (recommended: Yes / Yes / Yes; Large Messages only if the app has **Mail.ReadWrite**).

## Optional: clean up the secret when the setup record is deleted

Deleting the Table 409 record leaves the Service Password entry behind. Microsoft's own setup tables
(e.g. Table 1260) delete it in `OnDelete`. If you want the same, add to Table 409 `OnDelete`:

```
    VAR
      GraphMail@50100 : Codeunit 50400;
    ...
      GraphMail.DeleteClientSecret(Rec);
```

This is optional and not required by Codeunit 50400.

## v0.2 (NMG2.00): fields 50113..50115 – large attachments as download link

Optional. Needed by Codeunit 50400 version NMG2.00, which reads them **by name** (so they must exist even if
you never use links). With *Graph Link Threshold (MB)* = 0 (the default) nothing changes. Prerequisite: Table 50403
"Object Storage Profile" is imported (the TableRelation points to it), see [../README.md](../README.md).

| No.   | Name                       | Type    | Properties |
|-------|----------------------------|---------|------------|
| 50113 | Graph Link Storage Profile | Code 20 | TableRelation `"Object Storage Profile"` (Table 50403) |
| 50114 | Graph Link Threshold (MB)  | Integer | MinValue 0; 0 = off. Attachments of at least this size are uploaded and replaced by a link |
| 50115 | Graph Link Validity (Days) | Integer | InitValue 7, MinValue 1. Amazon S3 pre-signed URLs are limited to 7 days: for an Amazon S3 / S3-compatible profile Codeunit 50400 uses at most 7 days, whatever is entered here |

Insert after field 50112 (Option A: designer, Option B: TXT as above) and append `,NMG2.00` to the Version List:

```
    { 50113;  ;Graph Link Storage Profile;Code20  ;TableRelation="Object Storage Profile";
                                                   CaptionML=[DEU=Graph-Link-Speicherprofil;
                                                              ENU=Graph Link Storage Profile] }
    { 50114;  ;Graph Link Threshold (MB);Integer  ;MinValue=0;
                                                   CaptionML=[DEU=Graph-Link ab Größe (MB);
                                                              ENU=Graph Link Threshold (MB)] }
    { 50115;  ;Graph Link Validity (Days);Integer ;InitValue=7;
                                                   MinValue=1;
                                                   CaptionML=[DEU=Graph-Link gültig (Tage);
                                                              ENU=Graph Link Validity (Days)] }
```

How it works: when *Graph Link Threshold (MB)* > 0, Codeunit 50400 creates an `ObjectStorageClient` for the profile
(Codeunit 50402 `CreateClient`) and calls `GraphMailSender.UseLinkStorage(client, threshold bytes, validity minutes, '')`.
At send time the add-in uploads every attachment of at least that size under
`mail-attachments/{yyyy}/{MM}/{guid}/{file name}` (below the profile's *Key Prefix*) and appends a download link to the
body instead of attaching the file. The profile must support links: Azure Blob with shared key or SAS URL, or
Amazon S3 / S3-compatible. Azure Blob in Entra ID mode cannot create links (the send fails with that error).

Existing record: `InitValue` applies only to new records, so after compiling set *Graph Link Validity (Days)* on the
existing Table 409 record (Page 409) before you enable links; Codeunit 50400 uses 7 days when it is 0.
